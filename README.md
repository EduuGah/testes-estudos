# Aulas práticas – Desenvolvimento Mobile (UNIP)

Projeto Android (Java + XML) com um módulo por roteiro e o workflow que compila os apps,
executa cada um em um emulador Android 14 (API 34) e salva os prints em `prints/`.

| Módulo | Roteiro |
|---|---|
| aula1_primeiroapp | 1 – Conhecendo o Android Studio |
| aula2_login | 2 – Tela de login em XML |
| aula4_menu | 4 – Menu simples em XML |
| aula5_checkbox | 5 – CheckBox |
| aula6_sharedprefs | 6 – SharedPreferences |
| aula7_seguranca | 7 – Conceitos de segurança |

Os roteiros 3 e 8 (Flutter) foram executados no DartPad.
